========================================================================
             HERO SMS AUTOMATION SYSTEM - MANUAL & USER GUIDE
========================================================================

SYSTEM REQUIREMENTS:
* Operating System: Windows 10 or Windows 11 (64-bit)
* Internet Connection: Required for dependencies, buying numbers, and browser automation
* Installed Browser: Google Chrome (installed in its default location)

------------------------------------------------------------------------
METHOD 1: AUTOMATIC SETUP (RECOMMENDED)
------------------------------------------------------------------------
This is the fastest and easiest method. The system includes an automated 
launcher ("run.bat") that checks for Python, installs necessary 
dependencies, downloads browser components, and starts the server automatically.

Step 1: Package & Transfer the Project
1. Locate the "hero" project folder on the source PC.
2. Right-click the "hero" folder, select "Send to" -> "Compressed (zipped) folder".
3. Transfer the ZIP file to the new computer using a USB drive, cloud storage, or email.

Step 2: Extract & Launch
1. On the new computer, move the ZIP file to your preferred location (e.g., the Desktop).
2. Right-click the ZIP file and select "Extract All...", then click "Extract".
3. Open the extracted "hero" folder.
4. Double-click the "run.bat" file.

[NOTE: FIRST RUN]
The terminal window will open and automatically download Python (if missing), 
configure a virtual sandbox (.venv), install all script packages, and download 
Playwright Chromium libraries. This may take 1-3 minutes depending on your 
internet speed.

[NOTE: SUBSEQUENT RUNS]
Double-clicking "run.bat" will skip installation checks and start the server 
instantly.

Step 3: Access the Dashboard
Once the console prints "[OK] Setup complete! Starting Web UI Dashboard...":
1. Open your web browser (Chrome, Edge, etc.).
2. Navigate to: http://127.0.0.1:5000
3. Keep the terminal window open in the background while using the system. 
   Closing the terminal will shut down the server.

------------------------------------------------------------------------
METHOD 2: MANUAL STEP-BY-STEP INSTALLATION
------------------------------------------------------------------------
If you prefer to configure the environment manually or run into security 
policies that block batch scripts, follow this manual sequence:

Step 1: Install Python
1. Go to the official Python website: https://www.python.org/downloads/
2. Download Python 3.11 or Python 3.13 (64-bit installer for Windows).
3. Open the installer.
4. IMPORTANT: Check the box at the bottom that says "Add python.exe to PATH" 
   before clicking install.
5. Click "Install Now" and wait for the installer to finish.

Step 2: Extract the Project Files
1. Copy the project ZIP folder onto the new PC.
2. Extract the files to a directory on your system (e.g. C:\Users\L\Desktop\hero).

Step 3: Open Command Prompt in Project Directory
1. Open the extracted folder.
2. Click on the folder address bar at the top of the file explorer, type "cmd", 
   and press Enter.
3. A Command Prompt window will open already pointed to your project folder.

Step 4: Create a Virtual Sandbox (Optional but Recommended)
Run the following command to create an isolated Python virtual environment:
   python -m venv .venv

Step 5: Activate the Sandbox
   .venv\Scripts\activate.bat
(Your command prompt line will now be prefixed with (.venv) to indicate 
the sandbox is active).

Step 6: Install Required Packages
Install the required dependencies using the requirements.txt manifest:
   pip install -r requirements.txt

Step 7: Configure Playwright Browsers
Download the Chromium web drivers required by the Playwright engine:
   playwright install chromium

Step 8: Start the Web Dashboard
Launch the Flask backend server:
   python app.py

Open http://127.0.0.1:5000 in your browser to access the control dashboard.

------------------------------------------------------------------------
CONFIGURATION & FIRST RUN CHECKLIST
------------------------------------------------------------------------
Before starting a run on the new PC, ensure the following is configured:
1. Logged in to Hero SMS: Open your official Google Chrome profile and 
   ensure you are logged into your account at the Hero SMS website.
2. Setup config.json: Click the Settings tab on the Dashboard and verify 
   your Hero SMS login credentials (if using Auto-Login), Target Recovery 
   URL, and Default Chrome Profile settings. Click "Save Settings".
3. Verify Profile Availability: If using Multiple Accounts (automatic 
   profile spawning), make sure Chrome is fully closed so the script can 
   copy and spawn instances cleanly without profile lock conflicts.

------------------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------------------

1. Port 5000 is Already in Use
* Symptom: The console crashes immediately with a socket binding error.
* Solution: Another Python or system process is running on port 5000. 
  Close any background terminal windows or run the following command in 
  command prompt to kill the conflicting process:
     netstat -aon | findstr :5000
     taskkill /F /PID <PID_NUMBER>

2. Browser Session Locked (Cannot Spawn Chrome)
* Symptom: Script logs read "Playwright Connection Failed" or Chrome fails to open.
* Solution: Google Chrome locks directories when active. Fully close all 
  Chrome browser windows (check Task Manager for background "chrome.exe" 
  processes and end them) before running automation.
